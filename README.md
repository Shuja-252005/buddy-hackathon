# Buddy

Buddy is a Flutter mobile interface for delegating development work to AI agents. The app recreates the supplied AgentFlow design as a Buddy-branded project and chat experience.

## Run locally

```sh
flutter pub get
flutter run
```

## Project structure

- `lib/` — Flutter application source
- `test/` — Flutter tests
- `android/`, `ios/`, `web/`, `macos/`, `windows/`, `linux/` — platform runners
- `.github/workflows/` — GitHub Actions checks

## Git workflow

The default branch is `main`. Create a feature branch for changes and open a pull request before merging. Commit messages should describe the change, for example `Build Buddy agent flow interface`.
